# แดชบอร์ดตรวจสอบสถานะ

แดชบอร์ดของ SONNIE ให้บริการผ่านหน้าเว็บที่ [https://sonnie.tapb.ch](https://sonnie.tapb.ch) เป็นระบบมอนิเตอร์แบบเรียลไทม์ (อ่านอย่างเดียว) ที่ช่วยให้ผู้ดูแลและสมาชิกสามารถติดตามสถานะการทำงานของบอทได้ตลอดเวลา หน้าเว็บรองรับการใช้งานบนมือถือ และปรับเปลี่ยนตามธีมสว่าง/มืด (Light/Dark mode) อัตโนมัติ

---

## ใครที่สามารถเข้าสู่ระบบได้บ้าง?

การเข้าใช้งานแดชบอร์ดต้องเข้าสู่ระบบด้วยบัญชี Discord (ขอเพียงสิทธิ์ `identify` เพื่อดูชื่อและไอดี):

- **สมาชิกที่มีบทบาท TABP ในเซิร์ฟเวอร์ TAPB** (การตั้งค่าสำหรับโปรดักชันผ่าน `DASHBOARD_ROLE_IDS`)
- **ผู้ดูแลเซิร์ฟเวอร์** ที่มีสิทธิ์ Administrator หรือ Manage Server ในเซิร์ฟเวอร์ที่บอทอยู่
- **ผู้ใช้ที่ระบุไว้โดยเฉพาะ** ในรายชื่อ `DASHBOARD_ALLOWED_USERS`

หากบัญชีของคุณไม่มีสิทธิ์ ระบบจะแสดงหน้า 403 Forbidden แจ้งเตือนอย่างสุภาพ (ระบบจะตรวจสอบสิทธิ์ซ้ำอย่างน้อยทุก 10 นาที)

## รายละเอียดของแต่ละพาเนล (Panels)

หน้าแดชบอร์ดจะรีเฟรชข้อมูลอัตโนมัติทุก 5 วินาที โดยแบ่งออกเป็นพาเนลต่างๆ ดังนี้:

### 1. บอท (Bot)
แสดงภาพรวมการทำงานของโปรเซสบอท:
- **สถานะการเชื่อมต่อ**: 🟢 เชื่อมต่อกับ Discord Gateway แล้ว หรือ 🔴 ไม่ได้เชื่อมต่อ
- **Gateway Ping**: ความเร็วการตอบสนองกับ Discord (มิลลิวินาที)
- **ระยะเวลาทำงาน (Uptime)**: เวลาที่บอททำงานต่อเนื่องตั้งแต่เริ่มสตาร์ต
- **เวอร์ชัน (Build Info)**: หมายเลข Commit ของโค้ด, เวอร์ชัน Go, และสถาปัตยกรรมระบบ
- **เซิร์ฟเวอร์ที่บอทอยู่**: รายชื่อเซิร์ฟเวอร์ (Guilds) และจำนวนสมาชิก
- **การใช้ทรัพยากร**: หน่วยความจำที่ใช้ (Memory Alloc / Sys) และจำนวน Goroutines

### 2. ห้องอ่านแชท (TTS Sessions)
แสดงสถานะของห้องอ่านแชทที่กำลังดำเนินอยู่:
- สถานะการเปิดใช้งานระบบ TTS
- รายชื่อห้องเสียงที่บอทกำลังเข้าไปอ่าน
- รายชื่อห้องข้อความที่ผูกกับเซสชัน
- รายชื่อผู้เข้าร่วม พร้อมห้องข้อความที่ตนเองพิมพ์และเสียงพูดที่ได้รับมอบหมาย (เช่น `Puck (ชาย)`)
- เวลาที่เริ่มเซสชันและความยาวเวลา
- จำนวนข้อความในคิวที่รออ่าน (Queue)
- สถิติจำนวนข้อความที่อ่านไปแล้ว และจำนวนข้อความที่ถูกลบ

### 3. งบประมาณ Google TTS (TTS Budget)
ติดตามค่าใช้จ่ายและประสิทธิภาพของระบบแปลงข้อความเป็นเสียง:
- **เดือนปัจจุบัน**: เช่น พฤศจิกายน 2026
- **ยอดใช้จ่ายจริงเทียบกับงบประมาณ**: เช่น `฿36.20 / ฿300.00`
- **แถบความคืบหน้า**: แถบแสดงเปอร์เซ็นต์ (สีเขียว < 50%, สีเหลือง 50–79%, สีส้ม 80–99%, สีแดง 100%)
- **ความยาวเสียงที่สร้าง**: เวลาเสียงสะสมทั้งหมดในเดือนนั้น
- **สถานะการอ่าน**: 🟢 กำลังอ่าน (ปกติ) หรือ ⏸️ พักการอ่านชั่วคราว (เมื่องบเต็ม 100%)
- **วันเวลาที่รีเซ็ตงบประมาณ**: วันที่ 1 ของเดือนถัดไป
- **ความเร็วในการตอบสนอง (Recent Latency)**: เวลาที่รอจนกระทั่งได้ยินเสียงแรก (Time-to-first-audio) และช่องทางการสังเคราะห์เสียง (gRPC Streaming หรือ REST Fallback)

### 4. อีเวนต์ของเซิร์ฟเวอร์ (Events)
ติดตามการจัดกิจกรรมภายในเซิร์ฟเวอร์:
- **รายการอีเวนต์ที่กำลังจะมาถึง**: ชื่อกิจกรรม, วันเวลา, สถานที่หรือห้องเสียง, จำนวนผู้สนใจ, และภาพตัวอย่างรูปปก
- **การแจ้งเตือนที่รอดำเนินการ (Pending Reminders)**: แสดงเวลาที่บอทจะส่งข้อความแจ้งเตือนล่วงหน้า 15 นาที
- **สถานะระบบค้นหารูปปก (Cover Providers)**: สถานะของ Brave Search, Unsplash, Pexels, และ Openverse พร้อมระบุว่า Brave Search กำลังพักการค้นหาเนื่องจากโควตาหมดอยู่หรือไม่

### 5. Webhooks
แสดงการทำงานของช่องทางการส่งข้อมูลเข้าจากระบบภายนอก:
- ข้อกำหนดอัตราการส่ง: สูงสุด 30 ครั้งต่อนาทีต่อหนึ่ง webhook และขนาดข้อมูลไม่เกิน 64 KB
- รายชื่อ Webhook ที่เปิดใช้งานและห้อง Discord ปลายทาง
- **ประวัติการเรียกใช้งานล่าสุด (Recent Calls)**: แสดงเวลา, ชื่อ hook, รหัสสถานะ HTTP (เช่น 200, 400, 401, 429), IP ของผู้ส่ง, และขนาดข้อมูล *(ระบบไม่มีการบันทึกหรือแสดง Token และเนื้อหาข้อความเพื่อความปลอดภัย)*

### 6. Log ล่าสุด (Recent Logs)
แสดงบันทึกการทำงานของบอท 300 บรรทัดล่าสุด:
- ช่องค้นหาข้อความแบบเรียลไทม์ พร้อมไฮไลต์คำค้นหา
- มีระบบเซ็นเซอร์ข้อมูลลับอัตโนมัติ (Redaction) เช่น โทเค็นบอท, รหัสผ่านเซสชัน และ API Key ต่างๆ จะถูกแทนที่ด้วย `[redacted]` เสมอ
