# แดชบอร์ดตรวจสอบสถานะ

แดชบอร์ดของ SONNIE ให้บริการผ่านหน้าเว็บที่ [https://sonnie.tapb.ch](https://sonnie.tapb.ch) เป็นระบบมอนิเตอร์แบบเรียลไทม์ (อ่านอย่างเดียว) ที่ช่วยให้สมาชิกที่ได้รับอนุญาตติดตามสถานะการทำงานของบอทได้ตลอดเวลา หน้าเว็บรองรับการใช้งานบนมือถือ และปรับเปลี่ยนตามธีมสว่าง/มืด (Light/Dark mode) อัตโนมัติ คู่มือฉบับนี้ (`/docs`) อยู่ในระบบเดียวกัน จึงใช้กฎการเข้าถึงเดียวกัน

---

## ใครที่สามารถเข้าสู่ระบบได้บ้าง?

การเข้าใช้งานแดชบอร์ดต้องเข้าสู่ระบบด้วยบัญชี Discord (ขอเพียงสิทธิ์ `identify` เพื่อดูชื่อและไอดี) และต้องเข้าเงื่อนไขอย่างใดอย่างหนึ่งต่อไปนี้:

- **สมาชิกเซิร์ฟเวอร์ TAPB ที่มีบทบาท (Role) TABP** — เป็นกฎของระบบจริง ตั้งค่าผ่าน `DASHBOARD_GUILD_ID` และ `DASHBOARD_ROLE_IDS`
- **ผู้ใช้ที่ระบุไว้โดยเฉพาะ** ในรายชื่อ `DASHBOARD_ALLOWED_USERS` (เข้าได้ทันทีโดยไม่ต้องมีบทบาท)

> **หมายเหตุ:** เมื่อมีการตั้งค่า `DASHBOARD_ROLE_IDS` แล้ว การเป็นเจ้าของเซิร์ฟเวอร์หรือมีสิทธิ์ Administrator / Manage Server **ไม่ได้ทำให้เข้าแดชบอร์ดได้เอง** ต้องมีบทบาท TABP หรืออยู่ในรายชื่อ `DASHBOARD_ALLOWED_USERS` เท่านั้น กฎ "ผู้ดูแลเซิร์ฟเวอร์ (Administrator หรือ Manage Server)" ใช้เป็นทางเลือกสำรองเฉพาะเมื่อ**ไม่ได้ตั้งค่าบทบาท**ไว้เลย

หากบัญชีของคุณไม่มีสิทธิ์ ระบบจะแสดงหน้า 403 Forbidden แจ้งเตือนอย่างสุภาพ ระบบจะตรวจสอบสิทธิ์ซ้ำไม่เกินทุก 10 นาที (ผลที่ตรวจแล้วถูกจำไว้นานสูงสุด 10 นาที) ดังนั้นหากคุณเพิ่งได้รับหรือถูกถอนบทบาท การเปลี่ยนแปลงจะมีผลภายใน 10 นาที การเข้าสู่ระบบหนึ่งครั้งใช้ได้นาน 7 วัน

## รายละเอียดของแต่ละพาเนล (Panels)

หน้าแดชบอร์ดจะรีเฟรชข้อมูลอัตโนมัติทุก 5 วินาที (หยุดรีเฟรชเมื่อสลับไปแท็บอื่น) โดยแบ่งออกเป็นพาเนลต่างๆ ตามลำดับนี้ ทุกพาเนลอ่านข้อมูลจากหน่วยความจำของบอท จึงไม่รบกวน Discord:

### 1. บอท
แสดงภาพรวมการทำงานของโปรเซสบอท:
- **สถานะการเชื่อมต่อ**: ออนไลน์ หรือ ออฟไลน์ (ไม่ได้เชื่อมต่อกับ Discord Gateway) พร้อมค่า ping ของ gateway เป็นมิลลิวินาทีเมื่อออนไลน์
- **ชื่อบอท**, **เวลาที่เริ่มทำงาน** และ **ระยะเวลาทำงาน (Uptime)** ต่อเนื่องตั้งแต่เริ่มสตาร์ต
- **เวอร์ชัน**: หมายเลขรุ่นของบอท (เช่น `1.0.0`) หรือรหัส Commit หากไม่ได้ระบุรุ่นตอนสร้างอิมเมจ
- **เวอร์ชัน Go**, **จำนวน goroutines**
- **หน่วยความจำ (heap)** และ **หน่วยความจำจาก OS**
- **จำนวนรอบ GC** (garbage collection)
- **รายชื่อเซิร์ฟเวอร์ที่บอทอยู่** พร้อมจำนวนสมาชิก

### 2. เซสชันอ่านแชท
แสดงสถานะของห้องอ่านแชทที่กำลังดำเนินอยู่ (ถ้าฟีเจอร์ปิดอยู่จะแจ้งว่า `TTS_ENABLED=false` และถ้าไม่มีเซสชันจะแจ้งว่าไม่มีเซสชันตอนนี้):
- ห้องเสียงที่บอทกำลังอ่านอยู่ และชื่อเซิร์ฟเวอร์
- **เวลาที่เริ่มเซสชัน** (พร้อมบอกว่ากี่นาทีที่แล้ว)
- **ห้องแชท** ที่ผูกกับเซสชัน
- **คิว**: จำนวนข้อความที่รออ่าน
- **อ่านแล้ว** และ **ลบแล้ว**: จำนวนข้อความที่อ่านไปแล้ว และจำนวนข้อความที่บอทลบไปแล้ว
- **ตารางผู้เข้าร่วม**: ชื่อผู้ใช้ ห้องข้อความที่ผู้ใช้คนนั้นถูกอ่าน และเสียงพูดที่ได้รับมอบหมาย แสดงเป็นชื่อเสียงเฉยๆ เช่น `Puck`

### 3. งบ Google TTS
ติดตามค่าใช้จ่ายและประสิทธิภาพของระบบแปลงข้อความเป็นเสียง (ถ้ายังไม่ได้ตั้งค่า Google หรือปิดฟีเจอร์อ่านแชท จะแจ้งว่ายังไม่ได้เปิดมิเตอร์):
- **ยอดใช้งานเทียบกับขีดจำกัด**: เช่น `฿36.20 / ฿300.00` และเปอร์เซ็นต์ (หากใช้เสียงรุ่นเก่าที่นับตามตัวอักษร จะแสดงเป็นจำนวนตัวอักษร และถ้าไม่ได้ตั้งเพดานจะขึ้นว่า ไม่จำกัด)
- **แถบความคืบหน้า**: สีเขียว < 50%, สีเหลือง 50–79%, สีส้ม 80–99%, สีแดง 100%
- **เดือน**: เช่น พฤศจิกายน 2026
- **สถานะ**: ใช้งานได้ หรือ หยุดอ่านแล้ว (ครบงบ)
- **เสียงที่สร้าง**: ความยาวเสียงสะสมในเดือนนั้น
- **แจ้งเตือนที่ส่งแล้ว**: ระดับ 50% / 80% / 100% ที่เคยแจ้งไปในเดือนนี้
- **รีเซ็ต**: วันที่ 1 ของเดือนถัดไป (นับตามเวลา US/Pacific)
- **เวลาถึงเสียงแรก (ล่าสุด)**: ตารางความหน่วงของข้อความล่าสุด แยกตามเวลา ช่องทางสังเคราะห์เสียง (`stream` คือ gRPC Streaming, `rest` และ `rest-fallback` คือ REST) เวลาจนได้ยินเสียงแรก และเวลาทั้งหมด

### 4. อีเวนต์
ติดตามระบบอีเวนต์ของเซิร์ฟเวอร์ (พาเนลนี้ไม่แสดงภาพตัวอย่างรูปปก):
- **ตัวจัดเวลา**: ทำงาน หรือ หยุด
- **เตือนก่อน**: เวลาแจ้งเตือนล่วงหน้าและห้องที่ใช้ส่ง (หรือ ปิด)
- **เริ่ม/จบอีเวนต์ของคนอื่น**: อัตโนมัติ หรือ เฉพาะที่สร้างด้วยบอท (ตามค่า `EVENT_AUTO_START`)
- **รอบถัดไป**: เวลาที่ตัวจัดเวลาจะตื่นมาทำงานรอบต่อไป (หรือ ไม่มีงานค้าง)
- **แหล่งรูปปก**: ลำดับที่บอทลองค้นหารูป (Brave Search, Unsplash, Pexels, Openverse เฉพาะแหล่งที่ตั้งค่าไว้) และหาก Brave กำลังพักเพราะเครดิตหมดจะบอกว่า "พักถึง" เมื่อไร
- **รายการอีเวนต์ที่กำลังจะมาถึง**: ชื่อ (กดเปิดอีเวนต์ใน Discord ได้) สถานะ เวลาเริ่ม/จบ สถานที่ เซิร์ฟเวอร์ จำนวนผู้สนใจ เวลาที่จะแจ้งเตือน และว่าบอทเป็นผู้เริ่ม/จบให้หรือไม่
- **ผิดพลาด**: หากบอทเริ่มหรือจบอีเวนต์ใดไม่สำเร็จ จะแสดงจำนวนครั้งที่พลาด และเวลาที่จะลองใหม่ (หรือ เลิกลองแล้ว)

### 5. Webhooks
แสดงการทำงานของช่องทางการส่งข้อมูลเข้าจากระบบภายนอก:
- ข้อกำหนด: สูงสุด 30 ครั้งต่อนาทีต่อหนึ่ง webhook และขนาดข้อมูลไม่เกิน 64 KB
- **รายชื่อ Webhook** ที่เปิดใช้งาน ห้อง Discord ปลายทาง จำนวนครั้งที่ถูกเรียก และการเรียกล่าสุดพร้อมรหัสผลลัพธ์
- **การเรียกล่าสุด**: เวลา ชื่อ hook (ถ้าเป็นชื่อที่ไม่มีอยู่จริงจะมี `(?)` ต่อท้าย) รหัสสถานะ HTTP (เช่น 200, 400, 401, 429) พร้อมสาเหตุ และ IP ของผู้ส่ง *(ระบบไม่เก็บและไม่แสดง Token หรือเนื้อหาข้อความเพื่อความปลอดภัย)*

### 6. Log ล่าสุด
แสดงบันทึกการทำงานของบอท 300 บรรทัดล่าสุด:
- ช่อง **กรอง log**: พิมพ์คำเพื่อแสดงเฉพาะบรรทัดที่มีคำนั้น (ไม่สนตัวพิมพ์เล็ก-ใหญ่) พร้อมบอกจำนวนบรรทัดที่เหลือ ช่องนี้ใช้กรองเท่านั้น ไม่มีการไฮไลต์คำค้น
- มีระบบเซ็นเซอร์ข้อมูลลับอัตโนมัติ (Redaction) เช่น โทเค็นบอท, client secret, คีย์เข้ารหัสเซสชัน, API Key ต่างๆ และโทเค็นของ webhook จะถูกแทนที่ด้วย `[redacted]` เสมอ
