# ปัญหาที่พบบ่อย (Troubleshooting)

รวมปัญหาที่พบบ่อยในการใช้งาน SONNIE และวิธีแก้ไขอย่างเป็นขั้นตอน

---

## 1. Discord แจ้งว่า "This command is outdated"

- **สาเหตุ**: โปรแกรม Discord บนเครื่องของคุณยังจำแคชคำสั่ง (Slash Commands) เวอร์ชันเก่าของบอทอยู่ โดยเฉพาะหลังจากที่บอทเพิ่งได้รับการอัปเดตคำสั่งใหม่
- **วิธีแก้ไข**: กดคีย์ลัด **`Ctrl + R`** (สำหรับ Windows/Linux) หรือ **`Cmd + R`** (สำหรับ macOS) เพื่อรีโหลด Discord Client ตัวโปรแกรมจะดึงข้อมูลคำสั่งล่าสุดจาก Discord ทันที

---

## 2. บอทไม่ยอมอ่านข้อความออกเสียง (บอทเงียบ)

หากคุณพิมพ์ข้อความแล้วไม่ได้ยินเสียงบอทพูดในห้องเสียง ให้ตรวจสอบตามข้อต่อไปนี้:

1. **ผู้ดูแลยังไม่ได้เปิดฟีเจอร์**: หากบอทตอบว่า "บอทนี้ไม่ได้เปิดใช้การอ่านแชทออกเสียง" แสดงว่าฟีเจอร์ถูกปิดอยู่ (`TTS_ENABLED`) ให้แจ้งผู้ดูแล
2. **งบประมาณรายเดือนเต็ม (100%)**:
   - พิมพ์ `/tts usage` เพื่อดูสถานะ หากยอดเงินแตะงบประมาณ (ค่าตั้งต้น ฿300) ระบบจะหยุดสังเคราะห์เสียงชั่วคราวจนถึงวันแรกของเดือนถัดไป (ดูห้องแจ้งเตือน `TTS_ALERT_CHANNEL_ID` ถ้าผู้ดูแลตั้งไว้)
3. **ยังไม่ได้ลงทะเบียนในห้องข้อความนั้น**:
   - ระบบอ่านแชทเป็นแบบ Opt-in คุณต้องอยู่ในห้องเสียง และพิมพ์ `/tts join` ในห้องข้อความที่คุณต้องการให้บอทอ่าน
4. **อยู่คนละห้องเสียงกับบอท**:
   - บอทสามารถเข้าร่วมห้องเสียงได้เพียง **1 ห้องเสียงต่อเซิร์ฟเวอร์** ในเวลาเดียวกัน หากบอทกำลังอ่านอยู่ในห้องเสียงอื่นที่มีสมาชิกอยู่ จะไม่สามารถย้ายมาห้องของคุณได้จนกว่าห้องเดิมจะใช้งานเสร็จ
5. **ข้อความถูกกรองออกโดยอัตโนมัติ**:
   - บอทจะไม่พูดข้อความจากบอทหรือ webhook และข้อความที่กรองแล้วไม่เหลืออะไรให้อ่าน เช่น ข้อความว่าง มีแต่ไฟล์แนบ มีแต่อีโมจิกำหนดเอง (custom emoji) หรือมีแต่โค้ดบล็อก/สปอยเลอร์
   - ข้อความที่มีแต่ลิงก์ไม่ได้ถูกข้าม บอทจะอ่านว่า "ลิงก์" ส่วนข้อความที่ยาวมากจะถูกตัดที่ `TTS_MAX_CHARS` (ค่าตั้งต้น 200 ตัวอักษร) แล้วอ่านเท่าที่ได้
   - ข้อความต้องมาจากห้องข้อความที่คุณกด `/tts join` ไว้เท่านั้น ข้อความในห้องอื่นจะไม่ถูกอ่าน
   - ถ้าคิวเต็ม ข้อความที่รอนานที่สุดจะถูกทิ้ง และหากการสังเคราะห์เสียงล้มเหลว (เช่น บริการ Google ผิดพลาดหรือผู้ดูแลยังไม่ได้ตั้งค่า Google) ข้อความนั้นจะไม่ถูกอ่านเช่นกัน ให้แจ้งผู้ดูแล
6. **บอทขาดสิทธิ์ในห้องเสียง**:
   - ตรวจสอบว่าบอทมีสิทธิ์ **Connect (เชื่อมต่อ)** และ **Speak (พูด)** ในห้องเสียงนั้นๆ หรือไม่

## 3. การ์ดเซสชันขึ้นสีส้ม "⚠️ ไม่มีสิทธิ์ลบข้อความ"

- **สาเหตุ**: บอทขาดสิทธิ์ **Manage Messages (จัดการข้อความ)** ในห้องข้อความนั้น
- **ผลกระทบ**: บอทจะยังคงอ่านข้อความของคุณออกเสียงตามปกติ แต่จะไม่สามารถลบข้อความหลังอ่านเสร็จ (Auto-delete) และไม่สามารถลบข้อความเมื่อจบเซสชันได้
- **วิธีแก้ไข**: ให้ผู้ดูแลเซิร์ฟเวอร์เปิดการตั้งค่าของห้องข้อความนั้น (Edit Channel) ไปที่แท็บ Permissions และเปิดสิทธิ์ **Manage Messages** ให้กับบทบาทของ SONNIE
- **หมายเหตุ**: บอทตรวจสิทธิ์นี้ตอนโพสต์การ์ดของห้องนั้น ดังนั้นหลังแก้สิทธิ์แล้ว ให้ทุกคนออกจากเซสชัน (`/tts leave`) จนเซสชันจบ แล้วเริ่มใหม่ด้วย `/tts join` การ์ดใหม่จึงจะหายเป็นสีส้ม

## 4. แบบฟอร์มสร้างอีเวนต์ไม่เปิดขึ้นมา (Form not opening)

- **แจ้งเตือน "ฟอร์มนี้เก่าแล้ว (บอทเพิ่งอัปเดต) — เปิดใหม่ด้วย `/event create`"**:
  - เกิดจากการเปิดฟอร์มทิ้งไว้ แล้วบอทได้รับการอัปเดตที่เปลี่ยนแบบฟอร์ม (หมายเลขรุ่นของฟอร์มเปลี่ยน) ทำให้ฟอร์มที่เปิดค้างไว้ใช้ไม่ได้ ให้พิมพ์ `/event create` ใหม่อีกครั้ง การรีสตาร์ตบอทเพียงอย่างเดียวไม่ทำให้ฟอร์มหมดอายุ
- **ฟอร์มไม่ตอบสนอง**:
  - ตรวจสอบว่าคุณมีสิทธิ์ **Create Events** หรือ **Manage Events** ในเซิร์ฟเวอร์หรือไม่ หากไม่มีสิทธิ์ บอทจะปฏิเสธการสร้างอีเวนต์
  - หากสิทธิ์ถูกต้องแต่ฟอร์มไม่ขึ้น ให้กด `Ctrl + R` เพื่อรีโหลด Discord
- **บอทตอบว่าใส่เวลาไม่ถูก**: ช่องเวลาใส่ได้เฉพาะเวลา (วันที่ให้เลือกในช่อง **วัน**) และต้องเป็นเวลาที่ยังมาไม่ถึง ดูรูปแบบที่รองรับในหน้า [อีเวนต์ของเซิร์ฟเวอร์](/docs/20-events)

## 5. แดชบอร์ดเข้าไม่ได้ (HTTP 403 หรือ 503)

### HTTP 403 Forbidden (ไม่มีสิทธิ์เข้าถึง)
- **สาเหตุ**: บัญชี Discord ที่ใช้เข้าสู่ระบบไม่มีสิทธิ์ดูแดชบอร์ด
  - สำหรับเซิร์ฟเวอร์โปรดักชัน: ผู้ใช้ต้องเป็นสมาชิกเซิร์ฟเวอร์ TAPB และมีบทบาท **TABP** หรืออยู่ในรายชื่อ `DASHBOARD_ALLOWED_USERS` การมีสิทธิ์ Administrator หรือ Manage Server อย่างเดียว **ไม่เพียงพอ** เมื่อมีการตั้งค่าบทบาทไว้
  - เฉพาะกรณีที่ผู้ดูแลไม่ได้ตั้งค่าบทบาท (`DASHBOARD_ROLE_IDS`) เท่านั้น ผู้ที่มีสิทธิ์ Administrator หรือ Manage Server ในเซิร์ฟเวอร์ที่บอทอยู่จึงจะเข้าได้
- **วิธีแก้ไข**: ตรวจสอบว่าล็อกอินด้วยบัญชี Discord ที่ถูกต้องหรือไม่ หากถูกต้องแล้วแต่ยังเข้าไม่ได้ ให้ติดต่อผู้ดูแลเพื่อขอรับบทบาท TABP หรือให้เพิ่มไอดีของคุณใน `DASHBOARD_ALLOWED_USERS` (หากเพิ่งได้รับบทบาท ผลจะมีภายใน 10 นาที)

### HTTP 503 Service Unavailable (บริการไม่พร้อมใช้งาน)
- **ยังไม่ได้ตั้งค่าการเข้าสู่ระบบ**: เจ้าของบอทยังไม่ได้ตั้งค่าตัวแปร `DISCORD_CLIENT_SECRET`, `DASHBOARD_PUBLIC_URL` และ `DASHBOARD_SESSION_KEY` (ต้องตั้งครบทั้งสามตัว)
- **ตรวจสอบสิทธิ์ไม่ได้ชั่วคราว**: บอทไม่สามารถเชื่อมต่อไปยัง Discord API เพื่อตรวจสอบบทบาทของผู้ใช้ได้ หรือบอทเพิ่งเริ่มทำงาน/เพิ่งเชื่อมต่อใหม่และยังโหลดรายชื่อเซิร์ฟเวอร์ไม่เสร็จ ให้รอสักครู่แล้วรีเฟรชหน้าเว็บใหม่
- **บอทยังไม่พร้อม**: บอทเพิ่งเริ่มต้นระบบและยังไม่รู้ Application ID ของตัวเอง (รอให้เชื่อมต่อ Discord เสร็จ) ผู้ดูแลตรวจสอบสถานะการเชื่อมต่อได้ที่ `/healthz` ซึ่งตอบ 503 เมื่อบอทไม่ได้เชื่อมต่อกับ Discord Gateway
