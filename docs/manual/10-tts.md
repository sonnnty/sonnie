# อ่านแชทออกเสียง (/tts)

ฟีเจอร์อ่านแชทออกเสียง (Text-to-Speech) ช่วยให้สมาชิกในห้องเสียงสามารถรับฟังข้อความที่เพื่อนพิมพ์ในห้องแชทได้โดยไม่ต้องสลับหน้าจอไปดู โดยระบบจะอ่านเฉพาะข้อความของผู้ที่ลงทะเบียนเข้าร่วมเซสชันเท่านั้น

---

## การเริ่มใช้งานและการเข้าร่วม (`/tts join`)

1. **เข้าห้องเสียง (Voice Channel)** ที่ต้องการให้บอทไปพูด
2. ไปยัง**ห้องข้อความ (Text Channel)** ที่คุณต้องการพิมพ์ข้อความ แล้วพิมพ์คำสั่ง:
   ```
   /tts join
   ```
3. บอทจะเชื่อมต่อเข้าห้องเสียงของคุณ และส่ง **การ์ดเซสชัน (Session Card)** ลงในห้องข้อความนั้น พร้อมส่งข้อความส่วนตัว (ephemeral) แจ้งว่าคุณได้รับเสียงใด

> **หมายเหตุ:**
> - **หนึ่งเซิร์ฟเวอร์มีได้ 1 ห้องเสียงพร้อมกัน**: สมาชิกทุกคนที่ใช้งาน TTS ในเซิร์ฟเวอร์เดียวกันจะฟังเสียงผ่านห้องเสียงเดียวกัน
> - **อ่านได้หลายห้องข้อความพร้อมกัน**: หากเพื่อนของคุณอยู่ในห้องเสียงเดียวกัน แต่อยากพิมพ์ในห้องอื่น (เช่น `#games`) เพื่อนสามารถพิมพ์ `/tts join` ในห้องนั้นได้ บอทจะส่งการ์ดและอ่านข้อความจากห้องนั้นๆ ตามที่แต่ละคนกำหนด
> - **การย้ายห้องพิมพ์**: หากคุณพิมพ์ `/tts join` ในห้องข้อความใหม่ บอทจะย้ายการอ่านข้อความของคุณไปยังห้องใหม่ทันที

---

## เสียงพูดและการเลือกเสียง (`voice:`)

ระบบใช้เสียงพูดคุณภาพสูงจาก **Gemini-TTS** โดยแยกเสียงพูดเฉพาะของแต่ละบุคคล:

- **การสุ่มเสียงอัตโนมัติ**: เมื่อเข้าร่วมครั้งแรก บอทจะสุ่มเสียงผู้ชายจาก Voice Pool (16 เสียง ได้แก่ `Achird`, `Algenib`, `Algieba`, `Alnilam`, `Charon`, `Enceladus`, `Fenrir`, `Iapetus`, `Orus`, `Puck`, `Rasalgethi`, `Sadachbia`, `Sadaltager`, `Schedar`, `Umbriel`, `Zubenelgenubi`)
- **การหมุนรอบ (Round Rotation)**: บอทจะสุ่มเสียงที่ยังไม่ซ้ำกับใครในเซสชัน เมื่อใช้ครบทุกเสียงแล้วจึงจะเริ่มรอบใหม่
- **เสียงเดิมตลอดเซสชัน**: คุณจะได้ยินเสียงเดิมของคุณตลอดการใช้งาน แม้จะย้ายห้องข้อความ หรือออกจากห้องเสียงแล้วกลับเข้ามาใหม่
- **การเลือกเสียงเอง**: คุณสามารถเลือกเสียงที่ชอบได้ด้วยตนเองผ่านตัวเลือก `voice:` เช่น:
  ```
  /tts join voice:Puck
  ```
  ระบบมีระบบช่วยค้นหาอัตโนมัติ (Autocomplete) ทั้งเสียงชาย 16 เสียงและเสียงหญิง 14 เสียง (เช่น `Achernar`, `Aoede`, `Erinome`, `Kore`, `Leda`, `Zephyr` เป็นต้น) ในรายการจะมีป้าย `(ชาย)` หรือ `(หญิง)` กำกับ พิมพ์บางส่วนของชื่อ หรือพิมพ์ `หญิง` / `ชาย` เพื่อกรองรายการได้
  *(หมายเหตุ: เสียงผู้หญิงจะไม่มีการสุ่มอัตโนมัติ จะใช้งานได้เฉพาะเมื่อเลือกเองเท่านั้น)*

---

## การออกจากเซสชัน (`/tts leave`)

- พิมพ์ `/tts leave` เพื่อยกเลิกการอ่านข้อความของคุณ
- **ออกจากห้องเสียง = ออกจากเซสชันอัตโนมัติ**: หากคุณตัดการเชื่อมต่อจากห้องเสียงหรือย้ายไปห้องเสียงอื่น บอทจะนำคุณออกจากเซสชันให้อัตโนมัติโดยไม่ต้องพิมพ์คำสั่ง
- เมื่อสมาชิกคนสุดท้ายออกจากเซสชัน (หรือเหลือแต่บอทในห้องเสียง) เซสชันจะสิ้นสุดลง บอทจะออกจากห้องเสียงและเริ่มขั้นตอนทำความสะอาดข้อความ

---

## บอทอ่านอะไรบ้าง?

บอทอ่านเฉพาะข้อความของผู้ที่เข้าร่วมเซสชัน และเฉพาะที่พิมพ์ในห้องข้อความที่ผู้นั้นลงทะเบียนไว้ โดยจะปรับข้อความให้เหมาะกับการอ่านก่อน:

- ชื่อผู้ส่งจะถูกอ่านนำหน้าข้อความ (ผู้ดูแลปิดได้ด้วย `TTS_SPEAK_AUTHOR`)
- ลิงก์จะอ่านว่า "ลิงก์" การแท็กชื่อจะอ่านเป็นชื่อ (ถ้าบอทไม่รู้จักชื่อ จะข้ามไป) ส่วนอีโมจิกำหนดเอง (custom emoji), เวลา `<t:...>`, ข้อความสปอยเลอร์ และโค้ดบล็อกจะไม่ถูกอ่าน
- **ข้อความยาวจะถูกตัดแล้วอ่านเท่าที่ได้** ไม่ได้ข้าม โดยอ่านไม่เกิน `TTS_MAX_CHARS` ตัวอักษร (ค่าตั้งต้น 200)
- ข้อความจากบอทหรือ webhook ไม่ถูกอ่าน
- บอทอ่านทีละข้อความตามลำดับ หากคิวเต็ม (ค่าตั้งต้น 20 ข้อความต่อเซิร์ฟเวอร์) ข้อความที่รอนานที่สุดจะถูกทิ้งก่อน เพราะในแชทสดข้อความใหม่สำคัญกว่า

### เมื่อใดข้อความจึงไม่ถูกอ่าน?

ข้อความของผู้เข้าร่วมจะ**ไม่ถูกอ่าน** ในกรณีต่อไปนี้เท่านั้น:

1. **ไม่เหลืออะไรให้อ่านหลังกรองแล้ว** เช่น ข้อความว่าง มีแต่ไฟล์แนบ มีแต่อีโมจิกำหนดเอง หรือมีแต่โค้ดบล็อก/สปอยเลอร์ (ข้อความที่มีแต่ลิงก์ยังถูกอ่านเป็นคำว่า "ลิงก์")
2. **คิวเต็ม** และข้อความนี้เป็นข้อความที่รอนานที่สุดจึงถูกทิ้ง
3. **สังเคราะห์เสียงไม่สำเร็จ** (เช่น บริการ Google ผิดพลาดหรือตอบช้าเกิน 30 วินาที)
4. **งบประมาณเต็มแล้ว** (ดูหัวข้องบประมาณด้านล่าง)

## การลบข้อความอัตโนมัติ (Auto-Delete)

เพื่อรักษาความเป็นระเบียบเรียบร้อยของห้องแชท SONNIE มีระบบจัดการข้อความอัตโนมัติ 2 ขั้นตอน:

1. **ลบหลังอ่านจบ (8 วินาที)**: เมื่อบอทอ่านข้อความของคุณในห้องเสียงจบแล้ว ข้อความนั้นจะถูกลบทิ้งหลังจากนั้นประมาณ 8 วินาที (ค่าตั้งต้น ผู้ดูแลปรับได้ด้วย `TTS_DELETE_AFTER`)
   - ข้อความที่ไม่ถูกอ่าน (ตามเหตุผลในหัวข้อก่อนหน้า ได้แก่ ไม่เหลืออะไรให้อ่านหลังกรอง คิวเต็ม สังเคราะห์เสียงไม่สำเร็จ หรืองบเต็ม) จะถูกลบทิ้งหลังครบ 8 วินาทีเช่นกัน เพื่อไม่ให้ห้องรก
2. **ลบเมื่อจบเซสชัน (End of Session Cleanup)**: เมื่อเซสชันสิ้นสุดลง บอทจะสแกนและลบข้อความที่ตกค้างทั้งหมดของผู้เข้าร่วมที่พิมพ์ในห้องที่ตนเองลงทะเบียนไว้ นับตั้งแต่เวลาที่เข้าร่วมจนถึงเวลาจบเซสชัน (รวมถึงสิ่งที่พิมพ์ในห้องนั้นหลังจากกด `/tts leave` ไปแล้ว)

### ข้อความใดบ้างที่จะไม่ถูกลบ?
- ข้อความของผู้ใช้ที่ไม่ได้กด `/tts join`
- ข้อความที่พิมพ์ก่อนกดเข้าร่วมเซสชัน
- ข้อความในห้องที่ผู้ใช้ไม่ได้ลงทะเบียนให้อ่าน
- การ์ดสรุปของบอทเอง

> **⚠️ คำเตือน:** บอทจำเป็นต้องมีสิทธิ์ **Manage Messages (จัดการข้อความ)** ในห้องข้อความนั้น หากไม่มีสิทธิ์ การ์ดเซสชันจะแสดงแถบสีส้มพร้อมข้อความ `⚠️ ไม่มีสิทธิ์ลบข้อความ` โดยบอทจะยังอ่านข้อความตามปกติ แต่จะไม่สามารถลบข้อความได้

เมื่อจบเซสชัน การ์ดเซสชันจะเปลี่ยนเป็นสรุปข้อมูล เช่น:
```
📝 จบการอ่าน · @Alice @Bob · 25 นาที · ลบ 42 ข้อความ
```

## งบประมาณและการตรวจสอบการใช้งาน (`/tts usage`)

การอ่านออกเสียงด้วย Gemini-TTS มีงบประมาณตั้งต้นอยู่ที่ **฿300 ต่อเดือน** (ปรับได้ด้วย `TTS_MONTHLY_BUDGET_THB`) และรีเซ็ตทุกวันที่ 1 ของเดือนตามเวลาสหรัฐฯ / Pacific Time (ซึ่งตรงกับรอบบิลของ Google ไม่ตรงกับวันที่ 1 ตามเวลาไทย)

- ตรวจสอบยอดการใช้งานได้ตลอดเวลาด้วยคำสั่ง:
  ```
  /tts usage
  ```
  บอทจะตอบกลับเป็นข้อความส่วนตัว (เฉพาะคุณที่เห็น) แสดงแถบความคืบหน้า จำนวนเงินที่ใช้ไป เทียบกับงบประมาณของเดือนนั้น (ค่าตั้งต้น ฿300), จำนวนวินาทีเสียงที่สังเคราะห์ และเวลาที่จะรีเซ็ต
- **การแจ้งเตือน**: หากผู้ดูแลตั้งห้องแจ้งเตือนไว้ (`TTS_ALERT_CHANNEL_ID`) บอทจะส่งข้อความแจ้งเตือนลงในห้องนั้นเมื่อการใช้งานแตะระดับ (ตัวเลขด้านล่างคิดจากงบตั้งต้น ฿300):
  - 🟡 **50%** (฿150)
  - 🟠 **80%** (฿240)
  - 🔴 **100%** (฿300)
- **เมื่อแตะ 100%**: ระบบอ่านแชทจะ **พักการอ่านชั่วคราว** ข้อความที่พิมพ์ในช่วงนั้นจะไม่ถูกอ่าน (แต่ยังถูกลบตามปกติ) และจะกลับมาเปิดใช้งานอีกครั้งอัตโนมัติเมื่อขึ้นเดือนใหม่ ข้อความสุดท้ายที่ทำให้งบเต็มยังถูกอ่านตามปกติ ดังนั้นยอดอาจเกินงบได้เล็กน้อย (ไม่กี่สตางค์)
- หากไม่ได้ตั้งห้องแจ้งเตือน บอทจะไม่ส่งแจ้งเตือนใดๆ และยอดการใช้งานจะเริ่มนับใหม่จาก 0 ทุกครั้งที่บอทรีสตาร์ต
