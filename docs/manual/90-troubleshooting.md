# ปัญหาที่พบบ่อย (Troubleshooting)

รวมปัญหาที่พบบ่อยในการใช้งาน SONNIE และวิธีแก้ไขอย่างเป็นขั้นตอน

---

## 1. Discord แจ้งว่า "This command is outdated"

- **สาเหตุ**: โปรแกรม Discord บนเครื่องของคุณยังจำแคชคำสั่ง (Slash Commands) เวอร์ชันเก่าของบอทอยู่ โดยเฉพาะหลังจากที่บอทเพิ่งได้รับการอัปเดตคำสั่งใหม่
- **วิธีแก้ไข**: กดคีย์ลัด **`Ctrl + R`** (สำหรับ Windows/Linux) หรือ **`Cmd + R`** (สำหรับ macOS) เพื่อรีโหลด Discord Client ตัวโปรแกรมจะดึงข้อมูลคำสั่งล่าสุดจาก Discord ทันที

---

## 2. บอทไม่ยอมอ่านข้อความออกเสียง (บอทเงียบ)

หากคุณพิมพ์ข้อความแล้วไม่ได้ยินเสียงบอทพูดในห้องเสียง ให้ตรวจสอบตามข้อต่อไปนี้:

1. **งบประมาณรายเดือนเต็ม (100%)**:
   - พิมพ์ `/tts usage` เพื่อดูสถานะ หากยอดเงินแตะ ฿300 ระบบจะหยุดสังเคราะห์เสียงชั่วคราวจนถึงวันแรกของเดือนถัดไป (ดูห้องแจ้งเตือน `TTS_ALERT_CHANNEL_ID`)
2. **ยังไม่ได้ลงทะเบียนในห้องข้อความนั้น**:
   - ระบบอ่านแชทเป็นแบบ Opt-in คุณต้องอยู่ในห้องเสียง และพิมพ์ `/tts join` ในห้องข้อความที่คุณต้องการให้บอทอ่าน
3. **อยู่คนละห้องเสียงกับบอท**:
   - บอทสามารถเข้าร่วมห้องเสียงได้เพียง **1 ห้องเสียงต่อเซิร์ฟเวอร์** ในเวลาเดียวกัน หากบอทกำลังอ่านอยู่ในห้องเสียงอื่นที่มีสมาชิกอยู่ จะไม่สามารถย้ายมาห้องของคุณได้จนกว่าห้องเดิมจะใช้งานเสร็จ
4. **ข้อความถูกกรองออกโดยอัตโนมัติ**:
   - บอทจะไม่พูดข้อความที่มีแต่ลิงก์เว็บไซต์อย่างเดียว, มีแต่อีโมจิอย่างเดียว, ข้อความจากบอทหรือ webhook อื่น, หรือข้อความที่ตัดทอนแล้วไม่มีตัวอักษรเหลืออยู่
5. **บอทขาดสิทธิ์ในห้องเสียง**:
   - ตรวจสอบว่าบอทมีสิทธิ์ **Connect (เชื่อมต่อ)** และ **Speak (พูด)** ในห้องเสียงนั้นๆ หรือไม่

---

## 3. การ์ดเซสชันขึ้นสีส้ม "⚠️ ไม่มีสิทธิ์ลบข้อความ"

- **สาเหตุ**: บอทขาดสิทธิ์ **Manage Messages (จัดการข้อความ)** ในห้องข้อความนั้น
- **ผลกระทบ**: บอทจะยังคงอ่านข้อความของคุณออกเสียงตามปกติ แต่จะไม่สามารถลบข้อความหลังอ่านเสร็จ (Auto-delete) และไม่สามารถลบข้อความเมื่อจบเซสชันได้
- **วิธีแก้ไข**: ให้ผู้ดูแลเซิร์ฟเวอร์เปิดการตั้งค่าของห้องข้อความนั้น (Edit Channel) ไปที่แท็บ Permissions และเปิดสิทธิ์ **Manage Messages** ให้กับบทบาทของ SONNIE

---

## 4. แบบฟอร์มสร้างอีเวนต์ไม่เปิดขึ้นมา (Form not opening)

- **แจ้งเตือน "ฟอร์มนี้เก่าแล้ว (บอทเพิ่งอัปเดต) — เปิดใหม่ด้วย `/event create`"**:
  - เกิดจากการเปิดฟอร์มทิ้งไว้แล้วบอทมีการรีสตาร์ตหรืออัปเดตเวอร์ชัน ทำให้ฟอร์มเดิมหมดอายุ ให้พิมพ์ `/event create` ใหม่อีกครั้ง
- **ฟอร์มไม่ตอบสนอง**:
  - ตรวจสอบว่าคุณมีสิทธิ์ **Create Events** หรือ **Manage Events** ในเซิร์ฟเวอร์หรือไม่ หากไม่มีสิทธิ์ บอทจะปฏิเสธการเปิดฟอร์ม
  - หากสิทธิ์ถูกต้องแต่ฟอร์มไม่ขึ้น ให้กด `Ctrl + R` เพื่อรีโหลด Discord

---

## 5. แดชบอร์ดเข้าไม่ได้ (HTTP 403 หรือ 503)

### HTTP 403 Forbidden (ไม่มีสิทธิ์เข้าถึง)
- **สาเหตุ**: บัญชี Discord ที่ใช้เข้าสู่ระบบไม่มีสิทธิ์ดูแดชบอร์ด
  - สำหรับเซิร์ฟเวอร์โปรดักชัน: ผู้ใช้ต้องมีบทบาท **TABP** ในเซิร์ฟเวอร์ TAPB
  - สำหรับเซิร์ฟเวอร์ทั่วไป: ต้องมีสิทธิ์ Administrator หรือ Manage Server ในเซิร์ฟเวอร์ที่บอทอยู่ หรือระบุไว้ใน `DASHBOARD_ALLOWED_USERS`
- **วิธีแก้ไข**: ตรวจสอบว่าล็อกอินด้วยบัญชี Discord ที่ถูกต้องหรือไม่ หากถูกต้องแล้วแต่ยังเข้าไม่ได้ ให้ติดต่อผู้ดูแลเซิร์ฟเวอร์เพื่อตรวจสอบบทบาท

### HTTP 503 Service Unavailable (บริการไม่พร้อมใช้งาน)
- **ยังไม่ได้ตั้งค่าการเข้าสู่ระบบ**: เจ้าของบอทยังไม่ได้ตั้งค่าตัวแปร `DISCORD_CLIENT_SECRET`, `DASHBOARD_PUBLIC_URL` หรือ `DASHBOARD_SESSION_KEY`
- **ตรวจสอบสิทธิ์ไม่ได้ชั่วคราว**: บอทไม่สามารถเชื่อมต่อไปยัง Discord API เพื่อตรวจสอบบทบาทของผู้ใช้ได้ (ปัญหาเครือข่ายชั่วคราว) ให้รอสักครู่แล้วรีเฟรชหน้าเว็บใหม่
- **บอทยังไม่พร้อม (Gateway not connected)**: บอทกำลังอยู่ในช่วงเริ่มต้นระบบหรือตัดการเชื่อมต่อจาก Discord Gateway (ตรวจสอบสถานะผ่าน `/healthz`)
