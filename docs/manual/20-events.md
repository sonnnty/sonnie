# อีเวนต์ของเซิร์ฟเวอร์ (/event)

ฟีเจอร์ `/event` ช่วยให้สมาชิกสามารถสร้างและจัดการนัดหมายหรือกิจกรรม (Discord Scheduled Events) ภายในเซิร์ฟเวอร์ได้อย่างสะดวกรวดเร็ว โดยบอทจะช่วยค้นหารูปปกสวยๆ จากคลังภาพให้อัตโนมัติ พร้อมระบบแจ้งเตือนและเริ่ม/จบอีเวนต์ตามเวลา

---

## คำสั่งทั้งหมด

| คำสั่ง | หน้าที่ |
|---|---|
| `/event create` | เปิดแบบฟอร์มภาษาไทยสำหรับสร้างอีเวนต์ (ไม่ใส่พารามิเตอร์) |
| `/event create name: when: ...` | สร้างอีเวนต์แบบระบุตัวเลือก (ไม่มีแบบฟอร์ม เหมาะสำหรับผู้ใช้ระดับสูง) |
| `/event cover` | เปลี่ยนรูปปกอีเวนต์ (เลือกจากรูปที่ค้นได้ หรือแนบรูปเอง) |
| `/event edit` | แก้ไขข้อมูล เช่น ชื่อ วันเวลา สถานที่ หรือรายละเอียด |
| `/event cancel` | ยกเลิกอีเวนต์ โดยบอทจะขอให้ยืนยันก่อน (หากอีเวนต์กำลังดำเนินอยู่จะปิดอีเวนต์แทน) |
| `/event list` | แสดงรายการอีเวนต์ที่กำลังจะมาถึง เรียงตามเวลา พร้อมจำนวนคนที่กดสนใจ |

---

## การสร้างอีเวนต์ผ่านแบบฟอร์ม (`/event create`)

เมื่อพิมพ์ `/event create` โดยไม่ใส่ตัวเลือกใดๆ ระบบจะเปิดหน้าต่างแบบฟอร์ม **สร้าง Event**:

1. **ชื่อ event**: ชื่อกิจกรรมที่ต้องการนัดหมาย (บังคับ, สูงสุด 100 ตัวอักษร)
2. **วัน**: เลือกวันจัดกิจกรรมจากตัวเลือก (วันนี้ และ 24 วันถัดไป ตามเวลาประเทศไทย)
3. **เวลา**: ระบุเวลาของวันที่เลือก เช่น `20:00`, `3 ทุ่ม`, `บ่าย 2`, `19.30` (ระบบตั้งต้นไว้ที่ `20:00`) ช่องนี้ใส่ได้เฉพาะเวลา หากใส่วันที่ (ให้เลือกวันที่ในช่อง **วัน**) หรือใส่เวลาที่ผ่านไปแล้วของวันนี้ บอทจะปฏิเสธและแจ้งสิ่งที่คุณพิมพ์
4. **ห้องเสียง**: เลือกห้องเสียงที่จัดกิจกรรม (ระบบจะเลือกห้องเสียงที่คุณอยู่ให้อัตโนมัติ หากเว้นว่างไว้จะจัดเป็นอีเวนต์ภายนอกห้องเสียงที่ระบุสถานที่ว่า `Discord`)
5. **รายละเอียด**: รายละเอียดเพิ่มเติมของกิจกรรม (ไม่บังคับ, สูงสุด 1,000 ตัวอักษร)

เมื่อส่งแบบฟอร์ม อีเวนต์จะมีระยะเวลาตั้งต้น 2 ชั่วโมง (เปลี่ยนได้ด้วย `/event edit end:`) และบอทจะค้นหารูปปกให้อัตโนมัติ พร้อมส่งข้อความแจ้งเตือนที่มีปุ่ม **🔄 เปลี่ยนรูป** ให้กดเปลี่ยนรูปได้ทันที

### การสร้างแบบกำหนดพารามิเตอร์ (Options Path)
สำหรับผู้ใช้ที่ต้องการความรวดเร็ว สามารถใส่พารามิเตอร์ได้โดยตรง เช่น:
```
/event create name:เตะบอล when:ศุกร์นี้ 3 ทุ่ม place:#ห้องเสียง
```
พารามิเตอร์ที่รองรับ: `name`, `when`, `place`, `location`, `description`, `end`, `image`, `keywords`

---

## รูปแบบเวลาที่รองรับ (Times)

ระบบอ่านเวลาตามเขตเวลาประเทศไทย (Asia/Bangkok) ทั้งภาษาไทยและภาษาอังกฤษ (ใช้ได้กับ `when:` และ `end:`):
- **ภาษาไทย**: `ศุกร์นี้ 3 ทุ่ม` (วันศุกร์ที่จะถึง 21:00; `ศุกร์หน้า` คือวันศุกร์ของสัปดาห์หน้า), `พรุ่งนี้ 20:00`, `มะรืน 10.30`, `คืนนี้ ตีสอง` (02:00 ของคืนนี้), `วันเสาร์ 14.30`, `12/11 19:00`, `20 พ.ย. 69 19:00` และ `2026-11-20 19:00` (ปีเป็น ค.ศ. หรือ พ.ศ. ก็ได้), `สองทุ่มครึ่ง` (20:30), `บ่ายสอง` (14:00), `เจ็ดโมงเช้า` (07:00), `ห้าโมงเย็น` (17:00), `ตี 5` (05:00), `เที่ยง` (12:00), `เที่ยงคืน` (00:00)
- **ภาษาอังกฤษ**: `tomorrow 8pm`, `next friday 21:00`, `nov 20 7:30pm`
- **ระยะเวลาสิ้นสุด (`end:`)**: ระบุเป็นเวลาสิ้นสุดหรือความยาวกิจกรรมได้ เช่น `23:00`, `3 ชม.`, `90 นาที`, `1h30m` (ถ้าไม่ระบุ อีเวนต์ยาว 2 ชั่วโมง)
- หากระบุเวลาโดยไม่บอกวัน ระบบจะใช้ครั้งถัดไปที่เวลานั้นมาถึง (วันนี้หรือพรุ่งนี้) และปฏิเสธเวลาที่ผ่านไปแล้ว
- ช่องเวลาใส่ได้เฉพาะเวลา หากจะแท็กใครให้ใส่ใน `description`

## การค้นหาและเปลี่ยนรูปปก (`/event cover`)

บอทมีระบบค้นหารูปปกอัตโนมัติ โดยตัดและปรับขนาดภาพให้อยู่ในสัดส่วน 5:2 (800×320 พิกเซล) สำหรับ Discord Scheduled Events:

1. **ปุ่ม 🔄 เปลี่ยนรูป หรือคำสั่ง `/event cover`**:
   - เมื่อกดปุ่มหรือใช้คำสั่ง `/event cover event:<ชื่อ>` บอทจะแสดงภาพตัวเลือก 5 ภาพ พร้อมปุ่มหมายเลข **1**–**5** และปุ่ม **🔎 ค้นใหม่** (เฉพาะคุณที่มองเห็น)
   - กดปุ่มตัวเลขเพื่อเลือกภาพที่ต้องการ หรือกดค้นใหม่เพื่อดูภาพในหน้าถัดไป
   - สามารถพิมพ์คำค้นรูปปกเองได้ด้วยตัวเลือก `keywords:` (คำค้นภาษาอังกฤษจะได้ผลลัพธ์ที่ตรงและหลากหลายที่สุด) หรือแนบไฟล์ภาพของคุณเองผ่านตัวเลือก `image:`

2. **แหล่งที่มาของภาพ (Cover Providers)**:
   - **Brave Search API**: ค้นหาภาพจากเว็บทั่วไป (ค้นหาชื่อเกมหรือหัวข้อเฉพาะได้แม่นยำ) ภาพเหล่านี้เป็นภาพทั่วไปบนเว็บที่ **ไม่มีใบอนุญาตใช้ซ้ำ** เจ้าของบอทเลือกเปิดใช้เฉพาะในเซิร์ฟเวอร์เพื่อนส่วนตัวที่ไม่แสวงหากำไร เครดิตของภาพจะบอกแค่เว็บที่มา เช่น `📷 example.com · https://example.com/page`
   - **Unsplash / Pexels**: คลังภาพถ่ายคุณภาพสูง
   - **Openverse**: คลังภาพลิขสิทธิ์เสรี (Creative Commons)
   - ภาพที่ค้นพบจะมีการระบุเครดิตผู้สร้างและลิงก์ที่มาในบรรทัดสุดท้ายของคำอธิบายอีเวนต์ให้อัตโนมัติ (เช่น `📷 “Photo” — Author · CC BY`) ส่วนภาพที่คุณแนบเอง (`image:`) จะไม่มีบรรทัดเครดิต โปรดตรวจสอบให้แน่ใจว่าคุณมีสิทธิ์ใช้ภาพนั้น

3. **ระบบพักเครดิต Brave ชั่วคราว (Brave Credit Pause)**:
   - หากเครดิตการค้นหาภาพของ Brave Search ในเดือนนั้นหมดลง บอทจะส่งข้อความแจ้งเตือนหนึ่งครั้งในห้องแจ้งเตือนอีเวนต์ (`EVENT_CHANNEL_ID`) และสลับไปใช้รูปจาก Unsplash / Openverse แทนโดยอัตโนมัติจนกว่าโควตาจะรีเซ็ตในเดือนถัดไป

> **หมายเหตุ:** ตัวเลือกรูปที่เปิดค้างไว้ (ปุ่ม 1–5) จะใช้ไม่ได้หลังบอทรีสตาร์ต ให้พิมพ์ `/event cover` ใหม่

## ระบบแจ้งเตือนและเริ่ม/จบอีเวนต์อัตโนมัติ

- **แจ้งเตือนก่อนเริ่ม 15 นาที**: บอทจะส่งข้อความแจ้งเตือนในห้องอีเวนต์ (`EVENT_CHANNEL_ID` ถ้าไม่ได้ตั้งจะใช้ห้องเดียวกับ `TTS_ALERT_CHANNEL_ID`) พร้อมแท็กเรียกสมาชิกทุกคนที่กดปุ่มสนใจ (*Interested*) พร้อมการ์ดสรุปอีเวนต์ ผู้ดูแลปรับเวลาได้ด้วย `EVENT_REMIND_BEFORE` และถ้าไม่มีห้องแจ้งเตือนหรือตั้งเป็น `0` จะไม่มีการแจ้งเตือน อีเวนต์ที่สร้างใกล้เวลาเริ่มมากกว่าช่วงแจ้งเตือน (เช่น สร้างก่อนเริ่มไม่ถึง 15 นาที) จะไม่ได้รับการแจ้งเตือน และหากบอทปิดอยู่ตอนถึงเวลาแจ้งเตือน บอทจะข้ามไปโดยไม่ส่งย้อนหลัง
- **เริ่มอีเวนต์อัตโนมัติ**: เมื่อถึงเวลาเริ่ม บอทจะเปลี่ยนสถานะอีเวนต์เป็น กำลังดำเนินอยู่ (*Active*)
- **จบอีเวนต์อัตโนมัติ**: สำหรับกิจกรรมที่ไม่ได้จัดในห้องเสียง บอทจะปรับสถานะเป็น จบกิจกรรม (*Completed*) เมื่อถึงเวลาสิ้นสุด (สำหรับห้องเสียง Discord จะปิดให้อัตโนมัติเมื่อทุกคนออกจากห้องเสียง)
- **อีเวนต์ที่สร้างด้วย `/event` เริ่ม/จบให้เสมอ** ส่วนอีเวนต์ที่สมาชิกสร้างเองใน Discord บอทจะเริ่ม/จบให้เมื่อเปิด `EVENT_AUTO_START` (เปิดเป็นค่าตั้งต้น) และ **อีเวนต์แบบ Stage บอทจะไม่แตะต้อง**

## สิทธิ์ที่จำเป็น (Permissions)

- **สิทธิ์ของสมาชิก**:
  - สร้างอีเวนต์ (`/event create`): ต้องมีสิทธิ์ **Create Events** หรือ **Manage Events**
  - แก้ไข/เปลี่ยนปก/ยกเลิก (`/event edit`, `/event cover`, `/event cancel`): ต้องมีสิทธิ์ **Manage Events** หรือเป็นผู้สร้างอีเวนต์นั้น (คือผู้ที่พิมพ์ `/event create` หรือสร้างอีเวนต์ใน Discord เอง) หลังบอทรีสตาร์ต บอทจะจำไม่ได้ว่าใครเป็นผู้สร้างอีเวนต์ที่สร้างด้วย `/event` ผู้ที่มีสิทธิ์ Manage Events เท่านั้นจึงจะแก้ไขได้
- **สิทธิ์ของบอท**:
  - ต้องมีสิทธิ์ **Manage Events**, **Create Events**, **View Channel**, และ **Send Messages** ในห้องแจ้งเตือน
