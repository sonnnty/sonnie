# ภาพรวมการใช้งาน SONNIE

ยินดีต้อนรับสู่คู่มือการใช้งาน **SONNIE** บอท Discord ประจำเซิร์ฟเวอร์ที่ออกแบบมาเพื่ออำนวยความสะดวกในการพูดคุย เล่นเกม และจัดกิจกรรมร่วมกันในกลุ่มเพื่อน

SONNIE ทำงานแบบเปิดตลอด 24 ชั่วโมง โดยมีความสามารถหลัก 4 ด้าน:

1. **อ่านแชทออกเสียงในห้องเสียง (Text-to-Speech)**
   - อ่านข้อความที่คุณพิมพ์ลงในห้องแชทให้เพื่อนๆ ในห้องเสียงฟังแบบเรียลไทม์
   - ขับเคลื่อนด้วยโมเดล **Gemini-TTS** ให้เสียงพูดเป็นธรรมชาติเหมือนคนจริง
   - สุ่มแจกจ่ายเสียงผู้ชายเฉพาะบุคคล (16 เสียง) และสามารถเลือกเสียงเองได้ทั้งเสียงชายและหญิง
   - ลบข้อความที่อ่านแล้วอัตโนมัติเพื่อความเป็นระเบียบของห้องแชท

2. **สร้างและจัดการอีเวนต์ของเซิร์ฟเวอร์ (Scheduled Events)**
   - คำสั่ง `/event` สำหรับนัดหมายกิจกรรมพร้อมกรอกแบบฟอร์มภาษาไทยที่ใช้งานง่าย
   - ค้นหารูปปกสวยๆ ให้อัตโนมัติจากคลังภาพ (Brave Web Search, Unsplash, Pexels, Openverse) และมีปุ่มให้กดเปลี่ยนรูปเองได้ทันที
   - แจ้งเตือนล่วงหน้า 15 นาที และเริ่ม/จบอีเวนต์ให้อัตโนมัติ

3. **แดชบอร์ดตรวจสอบสถานะระบบ (Dashboard)**
   - หน้าเว็บสำหรับดูสถานะการทำงานของบอทแบบเรียลไทม์ที่ [https://sonnie.tapb.ch](https://sonnie.tapb.ch)
   - เข้าสู่ระบบด้วย Discord (สำหรับสมาชิกที่มีบทบาท TABP หรือผู้ดูแลเซิร์ฟเวอร์)
   - ดูห้องอ่านแชทที่กำลังทำงาน, งบประมาณการใช้งาน TTS ในเดือนปัจจุบัน, อีเวนต์ที่กำลังจะมาถึง, ประวัติ Webhook และ Log ล่าสุด

4. **ระบบรับส่งข้อความผ่าน Webhook (Generic Webhooks)**
   - รองรับการรับข้อมูลจากระบบภายนอก เช่น การแจ้งเตือนจาก CI/CD, Grafana, หรือ Alert Manager ผ่าน `POST /hooks/{name}` เพื่อส่งเข้า Discord
   - รองรับทั้งข้อความธรรมดาและ Embed รูปแบบสวยงาม พร้อมระบบจำกัดอัตราการส่งที่ปลอดภัย

## สารบัญคู่มือ

เลือกอ่านรายละเอียดการใช้งานแต่ละฟีเจอร์ได้จากหัวข้อด้านล่าง:

- [อ่านแชทออกเสียง (/tts)](/docs/10-tts) — วิธีเปิดใช้งาน, คำสั่ง `/tts join`, การเลือกเสียง, ระบบลบข้อความอัตโนมัติ และงบประมาณ
- [อีเวนต์ของเซิร์ฟเวอร์ (/event)](/docs/20-events) — การสร้างอีเวนต์ผ่านแบบฟอร์ม, การเปลี่ยนรูปปก, ระบบแจ้งเตือน และสิทธิ์ที่ต้องใช้
- [แดชบอร์ดตรวจสอบสถานะ](/docs/30-dashboard) — ใครเข้าดูได้บ้าง และรายละเอียดของแต่ละพาเนลบนหน้าเว็บ
- [Webhooks](/docs/40-webhooks) — รูปแบบข้อมูล, การยืนยันตัวตน, ข้อจำกัด และตัวอย่างคำสั่ง curl
- [ปัญหาที่พบบ่อย (Troubleshooting)](/docs/90-troubleshooting) — วิธีแก้ไขเมื่อพบปัญหา เช่น บอทไม่พูด, การ์ดเตือนไม่มีสิทธิ์ลบข้อความ, หรือเปิดแดชบอร์ดไม่ได้
